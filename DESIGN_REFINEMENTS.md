# Noted visual refinements

Large headings now use one relative tracking token, `--wb-brand-tracking: -.055em`, following the compact Noted wordmark and existing home headline. This applies consistently across Home, Add, Library, Review, Discover, Profile and Dictionary. Small labels, body copy and calendar month labels retain readable tracking. No font, route structure or visual identity was replaced.

Primary button groups use the existing 12px spacing token; compact mode controls retain their narrower spacing where needed on small screens. Existing page gutters, touch target minimums and naturally sized Review cards are preserved. The calendar section uses the shared 32px/24px spacing rhythm. Related-word pills and Voice Notes remain restrained secondary controls.

The learning calendar keeps the existing count bins: 0, 1–4, 5–14, 15–29, 30+. Reviewed uses four distinct lime/green strengths; Added uses a lavender progression, including the exact Add-page lavender brand token at the second step. A compact count legend supplements colour. Date text contrast against all eight activity colours exceeds 4.5:1 (the darkest purple is approximately 4.82:1 against #161616). Selection borders, today's underline, unavailable-history dashes, local dates and counting logic are unchanged. No historical data is fabricated or reset.
